# 戰鬥模擬器（sim/）

用真正的 `src/scenes/Battle.ts` 規則與 `src/data` 數值，無畫面快速打上千場。

```
node sim/build.mjs
node sim/out/sim.mjs 1000 all      # 各地點×等級×隊伍×玩家類型
node sim/out/sim.mjs 1000 巨岩     # 只跑某情境
node sim/out/sim.mjs --curve       # 升級曲線（照第一章順序打一遍）
TUNE='{"ENEMIES":{"rock":{"atk":20}}}' node sim/out/sim.mjs 600 巨岩   # 試調數值
```

- child（小孩）：大多按攻擊；有人 HP<40% 時 60% 機率吃餅乾（薄荷會補血）；偶爾對話（BOSS 後半 50%）。
- smart（會玩）：用技能、阿栗嘲諷、薄荷 55% 就補、BOSS 後半一定對話。
- 夥伴等級 = 主角 −1。40 回合沒結束算「卡住」。

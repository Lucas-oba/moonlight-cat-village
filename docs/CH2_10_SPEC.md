## 里程碑 1：三顆勇士之心（數值改版）

### 1.1 勇士稱號（勇氣值）
- 階級用勇氣值算：0 初期勇士、5 小小勇士、12 勇敢勇士、20 閃亮勇士、30 月光勇士。用一個函式 `heroTier(courage)` 回傳 0～4。
- 主角的職稱改成動態的，HUD、狀態頁、戰鬥都要顯示：「Lv 11・勇敢勇士」。主線 3 的獎勵文字「職業『初期勇士』」不用改。
- 存檔加 `titleTier`（已經慶祝過的最高階）。勇氣值增加後，如果 `heroTier` 比 `titleTier` 高，等目前的對話或戰鬥結束，就跳出**慶祝畫面**：
  - 徽章圖 `badge_tN` 放大、閃亮動畫，加上 sfx_levelup。
  - 系統說：「叮！{name}變成『小小勇士』了喵！」
  - 顯示禮物清單和一句誇獎（例如「妳害怕的時候，還是往前走了。」）。
  - 送貼紙 `title_tN`，放在貼紙簿的「勇士」頁（新頁）。
  - 一次跳好幾階時，一階一階依序慶祝。
- 禮物：
  - t1 小小勇士：主角學會技能「**我不怕！**」（MP 3，全隊 2 回合受到的傷害變少，沿用 `guardAll`，每場戰鬥 1 次）
  - t2 勇敢勇士：「勇氣揮擊」威力 1.7 → 2.0，揮的時候有金光特效
  - t3 閃亮勇士：飾品「閃亮勇士披風」（防禦 +2、HP +10）
  - t4 月光勇士：主角學會技能「**月光之心**」（MP 6，全隊回復 HP 30%，並解除不舒服的狀態，每場戰鬥 1 次）
- 舊存檔讀檔時：`titleTier` 預設是 0。如果勇氣值已經夠高，回到地圖時補慶祝（一階一階），補發所有禮物。

### 1.2 對話成功率跟著稱號（取代每 1 點 +5% 一路加到頂）
- 新的勇氣加成：`courageBonus(c) = 0.05·min(c,10) + 0.03·max(0,c−10) + 0.04·heroTier(c)`。
- 一般魔物：`talkChance = min(0.95, base + courageBonus + min(0.15, kindness·0.025) + purrBonus + moodBonus)`。
- 第一章頭目巨岩的 `bossTalkChance` **不改**。
- 單元測試（放在 sim 或 tests 裡都可以）：第一章所有一般魔物（`talkBase` 和 `talkBonus` 都要算進去），勇氣值 0～30，新的成功率 ≥ 舊公式 −0.06。不符合的話，調整 0.03 這個斜率（不要調其他數字），並在回報裡寫出最後的數字。
- 狀態頁的勇氣值旁邊顯示一行小字：「稱號越高，魔物越願意聽妳說話」。

### 1.3 「🦁 鼓起勇氣」選項
- 對話選項的資料加 `brave: true`：選項前面顯示 🦁，背景是金色。選了：勇氣值 +1，日記的「鼓起勇氣」次數 +1，再接一段小驚喜（多一句劇情、一個小道具或一張貼紙）。每個選項只會給一次（用旗標記）。
- 另一個普通選項一定可以選，故事照樣往前走。
- **少數特別的地方**（全部共 3 個）選項加 `minCourage: N`：
  - 勇氣值不夠時，選項是灰色的，寫著「🦁 再勇敢一點就能做到！（勇氣值 N）」。點了只說這句話，不會卡住。
  - 這 3 個地方都是**額外的寶物或捷徑**，絕對不是主線必經的地方。
- 第一章加 5 個 🦁 選項，放在現有對話的分歧點（請自己找適合的地方，例如第一次跟大個子守衛說話、跟著腳印走進草叢、巨岩戰之前、在黑森林找豆花）。其中 1 個要勇氣值（例如黑森林的「黑黑的樹洞」，勇氣值 8，裡面有寶物和貼紙）。
- 第二章已經做好的部分（c2m1～c2m6）加 2 個，0.10 的新內容再加 4 個。其中 2 個要勇氣值：迴聲谷的「高高的獨木橋」（勇氣值 15，寶物）、頭目戰前的「🦁 輕輕摸苔角的鼻子」（勇氣值 20，頭目戰一開始平靜 +1）。
- **測試要跟著改**：p2、p3、qsolve、p23 要能處理新選項，可以選任何一邊。回報裡列出全部 🦁 選項在哪裡。

### 1.4 觀察力：看穿心情、找弱點
- 魔物資料加 `mood`（`hungry` 肚子餓、`scared` 害怕、`lonely` 寂寞、`hurt` 好痛，可以不設定）和 `weak`（弱點的短句，例如「頭上的小花」）。所有現有魔物都要填。頭目也要填（巨岩：scared，苔角：hurt）。
- **觀察力 ≥ 3**：戰鬥開始時，魔物頭上會出現心情圖示（🍙／😨／💧／😣），點魔物或在情報裡可以看到說明，例如「牠好像肚子餓了。」第一次出現時，系統說明一次。
  - 照著心情做，叫做「**心情對了**」：
    - hungry：分享牠喜歡的食物（本來就會成功）
    - scared：這一回合主角選「防禦」或用「我不怕！」（表示不會傷害牠）
    - lonely：直接「對話」就算心情對了
    - hurt：對牠用回血的道具或回血技能（要讓回血道具和技能可以選魔物當目標，**只限 hurt 心情的魔物**）
  - 心情對了：這隻魔物的對話成功率 +0.25（`moodBonus`），並說一句「牠好像比較放心了。」
- **觀察力 ≥ 5**：情報裡也看得到弱點：「💥 弱點：頭上的小花」。主角和夥伴的普通攻擊、攻擊技能有**會心一擊**的機會：`min(0.3, 0.08 + 0.02·觀察力)`，傷害 ×1.5，畫面顯示「會心一擊！看準弱點了！」。觀察力不到 5，就跟現在一樣（沒有懲罰）。
- 探索：
  - 8 位 NPC 加 🔍「心裡的話」（觀察力達到門檻時，頭上出現 🔍 泡泡，點了聽到一句心裡話，給一張貼紙）。第一章 5 位，第二章 3 位，門檻在 2～6 之間。
  - 答題：**觀察力 ≥ 4** 時，答錯第一次後，除了原本的提示，再把一個錯的選項變灰：「🔍 觀察力幫妳刪掉一個不對的答案」。
- 狀態頁的觀察力旁邊顯示一行小字，寫出目前有用的效果（例如「看得到魔物的心情」）。

### 1.5 善良值：森林朋友來幫忙；第一章也有善良值
- **森林朋友**：存檔加 `befriended: Record<enemyId, number>`。對話成功或分享成功，該種魔物 +1。舊存檔從已經拿到的「對話」魔物頁貼紙推算。
- **來幫忙**：
  - 每場戰鬥最多 1 次。隊友回合開始時，如果有隊友 HP < 60%，或已經是第 3 回合以後，就有機會：`min(0.4, 0.1 + 善良值·0.01)`，條件是至少交過 1 種森林朋友。
  - 隨機挑一種森林朋友，滑進畫面（用牠的魔物圖，小一點、半透明），做一件事，再滑出去。**不會攻擊**：
    - heal 型（史萊姆、霧團子、蘑菇怪）：全隊回 15% HP
    - guard 型（哥布林、森林哥布林、森林野狼、迷霧野狼、咕咕）：下一次敵人的攻擊由牠擋掉
    - cheer 型（蝙蝠怪、哭哭菇、刺刺藤寶寶、松鼠鼬、迴聲蝙蝠、苔苔石）：解除全隊不舒服的狀態，下回合攻擊 +20%
  - 顯示文字：「霧團子來幫忙了！大家回復了一點 HP。」
  - 貼紙簿新增「森林朋友」頁，列出交過的朋友（自動）。
- **第一章補善良值**：整理第一章善良的劇情，例如：
  - 分菜給哥布林／把菜還給番薯伯的兩個選擇
  - 說服咕咕
  - 說服巨岩
  - 幫豆花找媽媽
  - 薄荷的草藥支線
  - 哥布林學寫字
  - 跟哥布林一起的月光宴會
  - 其他明顯是「幫別人」的支線
  
  用一張表 `CH1_KIND_EVENTS`（id → 條件 → 數值）：
  - 每一筆**只給一次**，記在 `kindAwarded`。
  - 讀檔時，和旗標或任務完成時，都檢查一次（舊存檔讀進來自動補，新玩家玩到就給）。
  - 數值：只玩主線約 +8，第一章全做約 +15。

  - `kindCh2`：在第二章（c2m1 開始以後）拿到的善良值。

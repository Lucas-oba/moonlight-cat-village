# 第三章「橋的另一頭」（友誼）製作規格（0.11.0）

依據：`CHAPTERS3_6_PROPOSAL.md`（先讀「✅ 已確認」，與下文衝突時以已確認為準）＋本檔。
本檔是給實作用的精簡規格；故事細節照提案第三章，**用字要給國小三～五年級：句子短、一句一件事、少用成語和抽象詞**。

## 0. 不能違反
- 一律用「勇士」，不用「戰士」。數值只增不減。答錯給提示不扣分。打輸照舊扣一點魚乾幣、被小白貓救回，**不扣任何數值**。
- 舊存檔（第一章、第二章、0.8.x～0.10）要能讀、能接著玩：只加新 id、新欄位在 `newState()` 給預設值。不改舊 id。
- 第一、二章的平衡不能變難（模擬比對）。
- 角色全部自創。圓圓、露露、捲捲、蓬蓬、慢慢的來歷不解釋。
- 不說教：重點是玩家按下去的動作；做完系統只說一句「剛剛妳做了什麼」。

## 2. 四個新數值（這一版就把四個都做好，第四～六章才會開始增加後三個）
照善良值的做法（state 欄位、HUD／狀態畫面、日記、舊存檔預設 0、只增不減、有上限的加成）。

| 欄位 | 名稱／圖示 | 效果（暫定數字，用模擬調） |
|---|---|---|
| `friendship` | 友誼值 🤝 | 夥伴接力：主角普通攻擊或技能攻擊命中後，機率 `min(0.30, 0.05 + 0.01·友誼值)`（友誼值 0 時不觸發），由一位還能行動的上場夥伴自動接一下（夥伴攻擊力約 50% 的小傷害，頭目戰只會打到「要打的東西」）。每回合最多一次。 |
| `honesty` | 誠實與負責值 🔔 | 說到做到：主角選「防禦」的那一回合，全隊受到的傷害再減 `min(0.30, 0.10 + 0.01·值)`（值 0 不觸發）。 |
| `love` | 愛心值 💞 | 暖暖的手：所有回血（技能、道具、森林朋友）多 `min(0.25, 0.01·值)`。 |
| `hope` | 希望值 ✨ | 希望之光：每場一次，有人血量低於 30% 時，機率 `min(0.60, 0.10 + 0.02·值)`（值 0 不觸發）全隊回 15% 最大血量。 |
- 狀態畫面：四個新數值放在勇氣、善良、觀察旁邊；**還沒拿到過（值是 0 而且還沒到那一章）的先不顯示或顯示「？」**，到該章才出現，避免第一章小朋友看不懂。
- 勇士日記：第三章那頁寫友誼值拿了多少和做過的友誼事件（照第二章日記的格式）。
- 第三章友誼值來源（各給一次，合計約 25～30）：送出／帶回朋友信、幫小穗點點把話說清楚、夥伴羈絆支線、一起托橋索、頭目戰對話、友誼相關支線。戰鬥裡用「夥伴接力」不加點（避免刷）。
- sim/sim.ts 要支援四個新數值（給參數），模擬報告列出。

## 3. 新夥伴 米舟
- 虎斑貓船家學徒，招募支線 c3s5「米舟的半張圖」。上場最多 3 人規則不變，後排可換人。
- 位置：中排／護衛。技能（照現有夥伴的數值級距，等級會跟著主角）：
  1. 「船墊護一下」：替一位隊友擋下一次傷害的一半（這回合）。
  2. 「划槳拍」：小傷害＋讓敵人速度下降。
  3. 羈絆 2 解鎖「一起划！」：自己和一位隊友這回合攻擊上升。
  4. 羈絆 4 解鎖「渡口的燈」：全隊回一點血＋解除一個壞狀態。
- 羈絆 1～4 的小事件放在營火／兩岸村（可以先做 1～3，4 留給第四章以後的支線，若要做就在本章的米舟羈絆支線裡）。
- 如果玩家暫時沒招募，主線需要時米舟以「當地朋友」身分在場（不進戰鬥）。

## 4. 【新機制】朋友信
- 介面：一張對折的紙（用 `c3_letter`）。左半寄信人、右半收信人。玩家替寄信人**從 3 句現成的話或 3 個小圖裡選一個**，交給收信人；收信人的回答會畫／寫在另一半，玩家帶回去交給寄信人。
- 全部單機、點選，不用打字。也可以選「直接幫他傳口信」，結果一樣（只是沒有信紙畫面）。
- 收到的信放進「背包 → 信」可以重看。第一次送信給 🤝+2。
- 主線 4～6 用一次（小穗 ⇄ 點點），支線再用 2～3 次。

## 6. 主線 12 個（id c3m1～c3m12，照提案，下面是實作重點）
1. **風往河邊走**：第二章完成後，在大樹根村找咕咕 → 葉尖上的紫絲 → 去迴聲谷找慢慢。（第二章章末畫面的「下一章」改成「第三章　橋的另一頭」）
2. **順著河彎**：慢慢的船載大家到蘆管灘（過場）。小穗在西岸敲木片，對岸沒回應。
3. **等不到的朋友**：陪小穗把兩人份點心帶回船棚 → 開放兩岸村；米舟說今天在對岸看到點點。
4. **幫我問一句**：小穗想問「妳今天也有來嗎？」→ 第一次用朋友信。開放 c3s5（米舟招募）。
5. **草後的黃布**：雙結橋找到點點，她畫回答／說「我揮到手都痠了」。
6. **兩邊都到了**：把回答帶回小穗，兩人才知道對方都有來 → 約好換岸試一次（渡船過場）。
7. **原來聽不到**：站東岸聽不到木片（水聲太大）、站西岸看不到布（蘆葦擋住）——用「站到對方的位置」的互動，觀察力閃光點提示。
8. **兩面布都升起來**：在兩個高處各插一支黃布旗（c3_flag），互相看見；橋下有第三片「帆」在動。
9. **會發抖的帆**：到橋下石灘，看到帆耳的耳朵被舊橋索纏住，紫絲繞進繩結。
10. **各托一小段**：小穗、點點用布旗打招呼，兩岸大人一起托穩舊索 → 進頭目戰（見第 7 節）。
11. **等你自己站起來**：頭目戰後的照顧時間＋帆耳慢慢站起來，索底露出紫色種子 → 放進小盆（`c3_seedpot`，之後跟著主角）。外側橋面打開。
12. **這次一起接船**：兩面布升起，兩個孩子一起接到「轉輪村來借水桶的船」；主角答應幫忙送桶 → 第三章完成、章末畫面、日記。懸念只放一點：小白貓領結又閃一下，只聽見半個「等……」。

## 7. 頭目戰：帆耳（照苔角）
- 背景 `bridgebg`，音樂 `boss3`。戰鬥前 🦁 選項（勇氣值夠才有額外效果，不擋主線）。
- 攻擊只能打「紫結舊橋索」（有血條）；帆耳本身不能被攻擊（點牠會變成對話）。
- 對帆耳「對話」累積「平靜」（照苔角）；友誼特色：**小穗、點點每回合有機會從兩岸揮旗**（類似森林朋友幫忙：加油＝下一次對話平靜多 +1 或替一人擋一點），友誼值越高機率越高。
- 橋索血量歸零＋平靜夠 → 照顧時間（點繩結解開最後一圈、陪牠站起來，點錯只會聽到帆耳的小聲音，不限時）。
- 不會失敗：全隊倒下也只是「小白貓扶大家站起來，再試一次」（照苔角的做法），不扣錢、不扣數值。
- 平衡：Lv 20 左右、1～2 位夥伴，平均約 7～10 回合（照苔角），sim 加情境。

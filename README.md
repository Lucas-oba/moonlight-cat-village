# 《月光貓村》試玩版 0.7

給小朋友玩的貓咪奇幻冒險 RPG。第一章主題：勇氣。

**線上試玩：** https://lucas-oba.github.io/moonlight-cat-village/

## 試玩內容
- 第一章主線 1～12、支線 22 個（含喵喵小學堂解題支線）
- 奇妙的地方：倒轉鐘樓、會說話的花園；喝露水變小、吃餅乾變大
- 解題：國語、英文、數學、自然（國小三～五年級）
- 夥伴阿栗、薄荷、柚子；回合制戰鬥（攻擊、技能、道具、防禦、逃跑、對話）
- 喵喵貼紙簿、魔物圖鑑、燈籠快速移動、哥布林交換小攤
- 可以走進去的房子、白天／夜晚、下雨天、夥伴羈絆與服裝

## 操作
- 左下角搖桿移動，或點地面自動走過去
- 點 NPC 或閃光點會走過去互動；往上走碰到門就能進屋子
- 右上角打開喵喵勇者系統

建議用手機直式畫面遊玩，電腦瀏覽器也可以玩。

## 音樂
遊戲裡的背景音樂和音效都是作者自己製作的作品。

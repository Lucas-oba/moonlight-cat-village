# 《月光貓村》試玩版 0.1

給小朋友玩的貓咪奇幻冒險 RPG。第一章主題：勇氣。

**線上試玩：** https://lucas-oba.github.io/moonlight-cat-village/

## 試玩內容
- 序章插圖、輸入名字、月光貓村與村外草原
- 主線任務 2～6、支線「找豆花」
- 喵喵勇者系統（狀態、任務日誌）
- 回合制戰鬥：攻擊、技能、道具、防禦、逃跑、對話
- 戰敗由小白貓救回村莊；在旅店或系統面板存檔（存在瀏覽器裡）

## 操作
- 左下角搖桿移動，或點地面自動走過去
- 點 NPC 或閃光點會走過去互動
- 右上角打開喵喵勇者系統

建議用手機直式畫面遊玩，電腦瀏覽器也可以玩。
